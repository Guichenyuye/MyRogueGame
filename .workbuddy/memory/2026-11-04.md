## 0.3.2 遗留问题修复（实机反馈 5 项）

- **问题一（剧毒药水后无法行动）**：敌人在敌方回合开始毒发致死（`tickEnemyStatusAtTurnStart`）后，`enemyTurn()` 只跳过死敌不判胜负，state 停在 PLAYER_TURN 却无活敌。修复：`enemyTurn()` 末尾补 `allEnemiesDead()` 判 VICTORY；`useItem()` 同理补兜底判胜。逻辑层 `useItem`/`useSkill` 本身无卡死（已用 Java17 控制台复现验证 state 正常）。
- **问题二（路径二选一只有一个能选）**：`connectLayers()` 用 `j=i*b/a`，第 1 层 a=1 时 j 恒 0，只连第 2 层 index0/1，index2 无前驱成孤立节点。修复：a==1 扇出到下一层全部节点；a>1 改 `j=i*(b-1)/(a-1)` 均匀分布 + 扇出 j/j+1。
- **问题三（鼠标点选路径）**：`MapScreen` 加 `selectableRects` Map 记录可选节点 Rectangle，点击进入（抽 `enterNode(node)` 公共方法供键盘/鼠标共用）；键盘数字键保留。顶栏/底栏提示改「点击节点继续」。
- **问题四（开局跳过第1层战斗）**：`RunState` 构造时 currentNode 直接设为第1层节点，导致 options() 返回第2层。修复：开局 `currentNode = null`，options() 在 null 时退回返回第1层节点。
- **问题五（普通战斗遇宝箱怪）**：`treasureMimic` 标记宝箱怪战斗胜利后未清除。修复：`onBattleWin()` 末尾 `treasureMimic = false`（与 eventCombat/battleFled 一起消费）。
- battleTest 337→**340 项全绿**（新增宝箱怪标记清除/毒发致死判胜/第1层扇出覆盖第2层 3 项断言）。

## 0.3.2 追加：空战斗拦截（防御性加固）

- 用户又反馈「死循环 + 空指针/越界」复合 bug 的担忧（空战斗→判定胜利→节点未 visited→留原地循环）。核对后确认上一步已修复绝大部分（毒发判胜/visited 标记/路线规划/墓渊奖励/道具悬停），本次补**唯一真正缺口**：空战斗兜底。
- **根因**：`createEnemies()` 在 `pending==null` 或 EnemyPool 抽参不对时可能返回空列表，玩家放技能即 VICTORY，若节点推进脱节就死循环。
- **修复**：`RunState.createEnemies()` 返回前统一检查，列表空则 `System.err` 告警（带节点类型）+ 兜底 `new Slime()`。宁可多打一场也不允许「空怪胜利」污染流程。
- **测试**：`check032` 新增断言——pending=null 兜底非空；200 地图普通战斗节点敌人非空；连续闯 3 节点层数严格递增 1→2→3→4 且每步 pending 清空。
- battleTest 340→**354 项全绿**。全量编译通过。文档 0.3.2.md 补第七节，测试计数 325→354。
