## 1. 这个版本加了什么

`0.1.1` 的问题是「打赢没有任何成长」。这个版本不急着做成长闭环，先把它的**地基**打好：天赋/技巧的数据结构、界面展示、触发反馈，以及金币/经验的字段。三选一升级和结算界面留给 `0.2.0`。

新增两件事玩家立刻能看到：

1. **战斗界面左侧面板分栏**：上半区「天赋」（金色标题），下半区「战斗技巧」（浅蓝标题）。归尘初始带一个天赋「血之泪」。
2. **血之泪触发有反馈**：非满血攻击命中时，面板里的「血之泪」会金色放大闪烁约 0.5 秒，同时日志打一条金色 `[天赋]` 记录。

| 类 | 职责 |
|---|---|
| `Talent` | 天赋静态定义（枚举 `Id`，带 `desc` 描述字段），目前只有 `BLOOD_TEAR` 一个 |

## 3. 已敲定的规则（本版新增）

1. **技能 CD 跨节点重置**：战斗胜利离开战斗界面时，所有技能冷却（真实 + 显示）强制清零，下一场战斗全部初始可用。
2. **天赋可见**：战斗界面左侧面板必须能看到拥有的天赋；天赋触发时名字金色放大闪烁 0.5s（借鉴《杀戮尖塔》遗物触发）。
3. **血之泪：回血按次数、闪烁按出手**。横扫打 2 个目标回 2 血（文档 2.7 不变），但面板只闪一次、日志只打一条——闪两下反而看不清。
4. **满血不触发**：血之泪满血时（实际回 0 点）不写日志也不闪，避免把提示做成噪音。
5. **日志前缀上色**（本版落地）：

| 前缀 | 含义 | 颜色 |
|---|---|---|
| `> ` | 玩家行动 | 青 |
| `< ` | 敌人行动 | 红 |
| `! ` | 非法操作（按错） | 橙 |
| `[天赋] ` | 天赋触发 | 金 |
| `** ` | 暴击 / 胜利 | 金 / 绿 |

   > `< ` 和 `! ` 分开，是因为原来敌人行动和「你按错了」都是红色会混。

6. **经验跨级保留**：`exp` 累加后用 `while` 循环扣减，升级时多余的不会清零。
7. **失败丢 `RunState`**：失败后回主菜单直接丢弃，重新开局 `new RunState()`，金币经验不保留（肉鸽惯例）。

## 4. 数值快照（本版新增）

| 项 | 值 |
|---|---|
| 金币掉落 | 战斗胜利 `+ 随机(10~15)` |
