# 归尘 · 0.2.0 — 成长系统闭环（结算界面 + 三选一 + 属性点 + 战斗技巧）

> **一句话**：打赢节点不再直接回地图，而是进入结算界面——领金币经验、升级三选一、分配属性点，角色在一局里真正变强了。

- 整理时间：2026-11-03
- 对应代码：`core/src/main/java/com/myname/roguelike/`（新增 `ResultScreen`，其余扩展）
- 复核方式：`./gradlew :core:battleTest` → 104 项全过

---

## 1. 这个版本加了什么

0.1.2 铺好了地基（金币/经验字段、天赋/技巧结构、CD 重置），这个版本把成长闭环做出来：

1. **战斗胜利 → 结算界面**（`ResultScreen`）：显示获得的金币、经验、当前经验进度条、等级。
2. **升级三选一**：经验够升级时弹出三个选项——技能升级 / 属性点 +1 / 随机战斗技巧。
3. **属性点分配（确认制）**：属性点不直接加到面板，先存入待分配池，玩家手动分配后按空格确认才生效，确认后不可撤回。
4. **5 个战斗技巧落地**：精打细算、破甲攻势、血怒、连击、护盾强化，在 `BattleSystem` 里真正生效。

---

## 2. 玩家能玩到的流程

```
战斗胜利 → 结算界面（金币 +X / 经验 +X / 进度条 / 等级）
        → 经验够升级？是 → 三选一（技能升级 / 属性点 / 技巧）
                          └ 选完 → 还可能再升级 → 再弹三选一（多级连升逐个处理）
        → 有待分配属性点？是 → 属性分配（[1]力量 [2]精准 [3]防御 [4]生命，空格确认）
        → 结算完成 → 按空格回地图
```

| 界面 | 内容 | 操作 |
|---|---|---|
| 结算页 | 金币、经验（当前/所需 + 进度条）、等级 | 空格继续 |
| 三选一 | 三个奖励：技能升级（金）/ 属性点（绿）/ 技巧（蓝） | `1` `2` `3` 选择 |
| 属性分配 | 四项属性当前值 + 本次临时 +N，剩余点数 | `1`~`4` 加点，空格/回车确认 |
| 结算完成 | 等级、金币汇总 | 空格回地图 |

## 3. 代码清单（本版改动）

| 类 | 改动 |
|---|---|
| `ResultScreen`（新增） | 结算界面，Phase 状态机 `RESULT → CHOICE → ATTRIBUTE → DONE` |
| `CombatSkill` | 加 `Id` 枚举 + 5 个静态技巧 + `ALL` 数组 |
| `Skill` | 加 `MAX_LEVEL = 5` + `levelBonusDamage(level)` |
| `Player` | 加 `skillLevels[4]`、`hasCombatSkill()`、`upgradeSkill()`、`addAttributePoint()`；`startTurn()` 接入精打细算 |
| `BattleSystem` | 5 个技巧的生效逻辑；技能等级加成叠加到伤害 |
| `RunState` | 经验按节点发放、`rollChoices()`/`applyChoice()`/`processLevelUp()`、内部类 `Choice`、保底计数 |
| `GameScreen` | 胜利后跳 `ResultScreen`（首领除外） |
| `BattleTest` | 92 → 104 项断言 |

**分层原则不变**：`ResultScreen` 只负责展示和接按键，所有数值结算在 `RunState` / `Player` / `BattleSystem`。

## 4. 数值快照（本版新增）

### 4.1 经验与升级

| 项 | 值 |
|---|---|
| 经验发放 | 普通战斗 8 / 精英 16 / 首领 24（都是 1 级升 2 级所需 8 的整数倍） |
| 经验曲线 | 斐波那契：升 2 级需 8、升 3 级需 13、升 4 级需 21…… |
| 每级奖励 | +2 点待分配属性点 |
| 经验跨级保留 | 多出的经验留在 `exp`，不会升级清零 |

### 4.2 三选一

| 选项 | 内容 |
|---|---|
| A 技能升级 | 随机一个未满级技能，等级 +1 |
| B 属性点 | +1 点待分配属性 |
| C 战斗技巧 | 随机一个未拥有的技巧；全拥有则换成属性点 |

**保底**：连续 2 次没抽到技能升级，第 3 次三个槽全出技能升级。

### 4.3 技能等级（0~5 级）

当前每级效果统一为「伤害 +2」（`levelBonusDamage(level) = level × 2`）。框架已留好：将来给每个技能设计差异化成长（如精准射击每级 +3、横扫加目标数），只改这一个方法。

### 4.4 属性点（1 点 = 一档）

| 属性 | 效果 |
|---|---|
| 力量 | +1（影响普攻/横扫伤害） |
| 精准 | +1（影响精准射击伤害） |
| 防御 | +1（影响减伤 + 护盾量） |
| 生命 | 最大生命 +5，同时当前生命 +5 |

### 4.5 五个战斗技巧

| 技巧 | 效果 | 触发位置 |
|---|---|---|
| 精打细算 | 回合开始精力回复 +1（+1 变 +2） | `Player.startTurn()` |
| 破甲攻势 | 攻击时敌人防御临时 -2（最低 0） | `BattleSystem.attackEnemy()` |
| 血怒 | 血量低于 30% 时最终伤害 ×1.2 | `BattleSystem.attackEnemy()` |
| 连击 | 普攻命中后 20% 追加一次半伤（不触发血之泪、不判暴击） | `BattleSystem.maybeCombo()` |
| 护盾强化 | 防御技能护盾量 ×1.5 | `BattleSystem.useSkill()` |

## 5. 已敲定的规则（本版新增）

1. **技能 CD 跨节点重置**（0.1.2 已定，本版沿用）：战斗胜利清空全部冷却。
2. **经验跨级保留**：`exp` 累加后用 `processLevelUp()` 循环扣减，多出的经验不清零。
3. **属性点确认制不可洗**：分配先记入临时区，按空格确认才写入面板；确认后不回退。
4. **三选一保底**：`skillUpgradeMissCount` 连续 2 次没出技能升级，第 3 次强制全技能升级。
5. **多级连升逐个弹**：`processLevelUp()` 一次只升一级，`ResultScreen` 逐级弹三选一，避免"打一场升两级只给一次三选一"。
6. **连击不触发血之泪、不判暴击**：连击本身已是奖励，再叠加回血/暴击会膨胀。

## 7. 已知问题与技术债

| 问题 | 影响 | 计划 |
|---|---|---|
| 三选一只出技巧，不出天赋 | 规格里「天赋只在精英节点获得」还没接，天赋目前只有初始血之泪一个 | 接精英节点奖励 |
| 连击 20% 随机未真机截图 | 逻辑有断言，但随机触发没在实机看到 | 下次回归补 |
| 属性分配无「确认前重置」按钮 | 按错了只能硬着头皮确认（规格只要求确认制不可洗，未要求重置） | 视体验决定是否加 |
| 技能等级当前只是 +2 伤害 | 差异化成长（每级不同效果）还没设计 | 0.2.1 或 0.3 再定 |
| 金币还没有消费出口 | 金币只进不出，商店没做 | 0.3.0 |
