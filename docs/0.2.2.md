# 归尘 · 0.2.2 — 节点重构与战斗细节完善（精英天赋 + 技能自选 + 事件系统）

> **一句话**：不引入金币消费，把非战斗节点做成真正的「决策」——精英必给天赋、三选一技能自选、宝箱防脸黑、篝火二选一、新增事件系统。

- 整理时间：2026-11-03
- 对应代码：`core/src/main/java/com/myname/roguelike/`（新增 `Event`、`AttributeAllocator`，改 `GameMap` / `MapScreen` / `ResultScreen` / `RunState` / `Talent` / `Player` / `BattleSystem`）
- 复核方式：`./gradlew :core:battleTest` → 148 项全过

---

## 1. 这个版本加了什么

0.2.1 修了体验，0.2.2 给地图上的每个节点都赋予了「选择」，让构筑有了深度：

1. **精英节点必给天赋**：精英战胜利 → 三选一 → 天赋二选一（从新天赋池抽 2 个不重复）。
2. **三选一技能升级改自选**：选中「技能升级」进入子阶段，平铺 4 个技能让玩家自选升级哪个。
3. **天赋池扩充**：新增铁壁、狂暴、贪婪、顽强 4 个天赋，凑齐可抽取的池子。
4. **宝箱防脸黑**：随机三种奖励（天赋/技能/生命），连续 2 次开天赋则第 3 次强制不给。
5. **篝火二选一**：休息回 30% 血 / 冥想 +2 属性。
6. **事件系统**：新增 EVENT 节点，内置灌木丛、废弃营地、神秘祭坛 3 个事件。

## 3. 玩家能玩到的流程

```
战斗胜利 → 结算（金币/经验）→ 三选一（技能自选/属性点/技巧）
         → 选「技能升级」→ 技能自选子阶段（4 技能挑一个 +1）
         → 选完 → 结算经验升级 → [精英？] 天赋二选一 → 属性分配 → 完成回地图

地图节点 → 战斗节点 → 战斗
        → 精英节点 → 战斗（胜利后额外天赋二选一）
        → 篝火节点 → 二选一（休息 30% 血 / 冥想 +2 属性）
        → 宝箱节点 → 随机奖励（天赋/技能/生命+5 回满）
        → 事件节点 → 二选一（灌木丛/营地/祭坛）
```

| 界面 | 内容 | 操作 |
|---|---|---|
| 三选一 | 技能升级(自选)/属性点/技巧/金币 | `1` `2` `3` |
| 技能自选 | 4 个技能 + 当前等级，满级置灰 | `1`~`4` |
| 天赋二选一 | 2 个天赋（名称 + 说明） | `1` `2` |
| 篝火抉择 | 休息 / 冥想 | `1` `2` |
| 事件抉择 | 事件描述 + 两选项 | `1` `2` |
| 宝箱结果 | 随机奖励结算文字 | 空格 |

## 5. 五个天赋（0.2.2 池子）

| 天赋 | 效果 | 触发位置 |
|---|---|---|
| 血之泪 | 造成伤害回 1 血 | `BattleSystem.attackEnemy` |

## 7. 已敲定的规则（本版变更）

1. **精英战奖励**：三选一 + 天赋二选一都触发；天赋池凑不够 2 个时转 +2 属性点。
2. **技能升级自选**：三选一的「技能升级」不再随机指定，进入子阶段自选；全满级时替换为 +15 金币。
3. **宝箱防脸黑**：`consecutiveTalentFromTreasure` 连续 2 次开天赋，第 3 次强制不给。
4. **篝火二选一**：休息（30% 回血）/ 冥想（+2 属性）。
5. **天赋获得统一走 `grantTalent`**：顽强这类「获得即生效」的天赋必须走这个方法，不能直接 `talents.add`。
