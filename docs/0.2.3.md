## 1. 这个版本改了/加了什么

0.2.3 是一次「推倒重来」的构筑大更新，核心是把伤害计算收敛成一条管线，同时把天赋/技巧/技能三个池子全部重构：

1. **Bug 修复**：事件/篝火给属性点后，未分配完**不可离开**地图（强制进属性分配界面）。
2. **战斗技巧分池**：新增 `isExclusive` 字段，通用池 6 个 + 归尘专属 3 个。
3. **三选一重构**：槽 2 属性点从 +1 提到 +2；槽 3 战斗技巧改为「抽 2 个自选 1 个」。
4. **天赋池整体重做**：废除铁壁/狂暴/贪婪/顽强，换成 6 个新天赋。
5. **精英奖励改二选一**：天赋 vs 技能（不再二选一天赋）。
6. **可替换技能**：新增蓄力 / 多重射击 / 血刺，精英战给技能后进入替换界面（只替换槽 3 / 槽 4）。
7. **伤害管线大一统**：`calculateDamage` 成为唯一伤害路径，旧效果全部迁移，严禁两套并行。
8. **普攻改远程**：普攻改名「随心一箭」并设为远程类型，伤害不再单独区分「普攻」维度，只按近战 / 远程 / AOE 三类结算；伤害公式由**力量**改为**精准**（精准×1.2+5）；删除「近战强化·普攻」「武器打磨」两个普攻专属技巧，换成「随性」（随心一箭暴击率 +10%）。

> 0.2.3 中段调整：删除了两个普攻专属的数值技巧（近战强化·普攻 ×1.1、武器打磨·普攻 +1），

## 4. 可替换技能（3 个新技能）

| 技能 | 精力 / CD | 类型 | 效果 |
|---|---|---|---|
| 蓄力 | 2 / 2 | 防御类 | 获得蓄力 Buff，下次攻击 ×2.5 |
| 多重射击 | 4 / 2 | AOE | 对所有敌人造成 精准×1.5 + 5 |
| 血刺 | 3 / 1 | 近战多段 | 对最前方敌人造成 3 次 力量×0.2 + 1 |

**获取方式**：精英战胜利后选「技能」→ 进入替换界面 → 选槽 3 或槽 4 替换。被替换的旧技能放回技能池，后续可再抽到。槽 1（随心一箭）/ 槽 2（防御）锁死不可替换。开局槽 3/槽 4 仍是固定的精准射击 / 横扫。

## 5. 伤害结算管线（唯一路径）

优先级（严格按顺序）：

1. **基础值**：技能公式（含等级加成）。
2. **乘区组合**：近战 / 远程 / AOE 三类乘区，**同类相加、不同类相乘**。
3. **特殊触发**：不惧疼痛（扣 2 血 ×1.1）→ 脱离掌控（×2.5）→ 慵懒之徒 Buff（×1.2）→ 蓄力 Buff（×2.5）。
4. **暴击判定**：×1.5（随心一箭若有「随性」技巧，暴击率 +10%）。
5. **防御减伤**：`伤害 × (1 - 防御/(防御+25))`。

**多段**：温和之人（近战 ×0.6 但段数翻倍）和血刺（3 段）用循环包裹 1~5 步，每段独立判暴击、减伤、血之泪。双重打击是特例（固定 1 点，跳过一切加成和回血）。

> **0.2.3 中段调整**：伤害不再区分「普攻」这一独立维度，只按近战 / 远程 / AOE 三类结算。
> 普攻改名「随心一箭」并设为远程类型，因此吃远程系加成（远程强化 ×1.1 / 箭术大师 ×1.5 / 血之回响回血）。
> 血之回响从「精准射击专用」上移到管线，对所有远程攻击生效。

## 6. 玩家能玩到的流程

```
战斗胜利 → 结算（金币/经验）→ 三选一（技能升级 / 属性点+2 / 战斗技巧二选一）
         → 选「技能升级」→ 技能自选子阶段（4 技能挑一个 +1）
         → 选「战斗技巧」→ 技巧二选一子阶段（通用+专属池抽 2 个）
         → 精英战额外 → 天赋/技能二选一
             → 选天赋 → 随机 1 个天赋
             → 选技能 → 替换子阶段（槽 3 / 槽 4 二选一）
         → 结算经验升级（+2 属性点）→ 属性点分配 → 完成回地图
```

非战斗节点（篝火/事件）给了属性点后，按空格会先被拦截进属性分配界面，分配完才能继续。
