# 归尘 · 0.2.4 — 数值回调与角色选择界面

> **一句话**：把全途径的自由属性点收益从 +2 回调到 +1，灌木丛「绕道」改成回血，并搭好多角色的底层架构（角色选择过渡界面 + 数据驱动）。

- 整理时间：2026-11-03
- 对应代码：改 `RunState` / `ResultScreen` / `MapScreen` / `Event` / `StartScreen`，新增 `CharacterType` / `CharacterData` / `CharacterSelectScreen`
- 复核方式：`./gradlew :core:battleTest` → 173 项全过

---

## 1. 这个版本改了/加了什么

1. **全途径属性点收益回调（+2 → +1）**：三选一属性点选项、篝火冥想、升级奖励、灌木丛事件「进入」、精英奖励兜底，统一降为 +1。
2. **灌木丛事件调整**：选项 1「绕道」从「+1 属性」改为「恢复 5 点生命」——绕道避开了危险但没拿到奖励，给玩家一个低风险的续航选项；选项 2「进入」保持「-10 生命 +1 属性」结构，属性从 +2 随全局回调降为 +1。
3. **新增角色选择过渡界面**：主菜单按 [1] 后不再直接进地图，而是先到角色选择界面锁定角色。

---

## 2. 属性点收益回调（+2 → +1）

| 途径 | 原值 | 新值 | 位置 |
|---|---|---|---|
| 三选一「属性点」选项 | +2 | +1 | `RunState.applyChoice` |
| 篝火「冥想」 | +2 | +1 | `RunState.resolveRest` |
| 升级奖励 | +2 | +1 | `RunState.processLevelUp` |
| 灌木丛「进入」 | +2 | +1 | `Event.BUSH` |
| 精英奖励兜底（天赋/技能池都空） | +2 | +1 | `ResultScreen.maybeEliteRewardOrAttribute` |

## 3. 事件系统调整

**灌木丛**（`Event.BUSH`）：

| 选项 | 原效果 | 新效果 |
|---|---|---|
| 绕道 | +1 自由属性 | **恢复 5 点生命** |
| 进入 | -10 生命，+2 属性 | -10 生命，**+1 属性**（不变结构，数值随回调） |

事件界面的选项按钮文字（`option1Text` / `option2Text`）已同步显示新效果，玩家在选择前能看清每个选项的收益。

## 4. 角色选择架构

**新增文件**：

- `CharacterType.java`：角色类型枚举，目前只有 `GUICHEN`（归尘）。
- `CharacterData.java`：角色静态数据（名字 / 一句话介绍 / 初始天赋），提供 `ALL` 数组。
- `CharacterSelectScreen.java`：角色选择界面，居中标题「选择你的角色」+ 角色列表 + 底部按键提示。

**关键约定**：角色名 / 介绍**不硬编码在 UI 里**，`CharacterSelectScreen` 只循环渲染 `CharacterData.ALL`。以后加新角色只需在 `CharacterType` 加枚举 + `CharacterData` 加一条数据，UI 不用改。

**流程变更**：

```
主菜单按 [1] → 角色选择界面（列出 [1] 归尘 + 介绍）
            → 按 [1] 锁定归尘，new RunState(GUICHEN)，进地图
            → 按 [ESC] 返回主菜单
```

`RunState` 新增 `character` 字段（`CharacterType`，默认 `GUICHEN`），并新增 `RunState(CharacterType)` 和 `RunState(long, CharacterType)` 两个构造器。未来多角色时，`Player` 可按 `character` 读取不同的初始面板 / 初始天赋 / 专属技巧池（架构已预留，当前只有归尘，面板仍走 `Player` 默认值）。

## 5. 玩家能玩到的流程（不变，仅开头多一步选角色）

```
主菜单 → 选角色 → 地图 → 战斗 → 结算 → 三选一（技能升级 / 属性点+1 / 技巧二选一）
                    → 精英战额外 → 天赋/技能二选一 → 替换技能
                    → 升级（+1 属性点）→ 属性分配 → 回地图
非战斗节点：篝火（休息 / 冥想 +1）· 宝箱 · 事件（灌木丛绕道回血 5 / 进入 -10 血 +1 属性）
```
