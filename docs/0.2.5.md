# 归尘 · 0.2.5 — 敌人预制池、新角色与中途重开

## 一、敌人预制池（EnemyPool）

废除原先「在 `RunState.createEnemies()` 里直接按层数写 if」的做法，新建 `EnemyPool`，按节点类型和层数抽取。`RunState.createEnemies()` 改为一行委托：

```java
return EnemyPool.create(pending.type, pending.floor, rng);
```

| 节点 | 层数 | 敌人 |
|---|---|---|
| 普通战斗 | 1~3 | 100% 史莱姆 |
| 普通战斗 | 4~6 | 50% 强化史莱姆 / 50% 骸骨战士 |
| 普通战斗 | 7 | 骸骨猎手 + 小史莱姆 |
| 精英战斗 | 1~4 | 100% 史莱姆王 |
| 精英战斗 | 5~7 | 50% 骸骨猎手（强化）/ 50% 史莱姆王 |
| Boss | 8 | 腐化史莱姆王 |

## 二、新增敌人：骸骨战士（BoneWarrior）

- HP 35，防御 2。
- 四步循环：轻击(5) → 骨质增生 → 轻击(5) → 重击(11)。
- **骨质增生**：恢复自身 10 点生命，本场战斗后续伤害永久 +2（类似史莱姆的「包裹」增伤，但回血是本怪独有的续航）。
- 意图栏准确显示加成后的伤害。

## 三、新增敌人：骸骨猎手（BoneHunter）

- 普通 HP 28 / 精英 HP 45，防御 1。
- 五步循环：速射(4) → 仔细瞄准 → 速射(4) → 仔细瞄准 → 骨箭。
- **仔细瞄准**：获得「下次攻击伤害翻倍」Buff。
- **骨箭**：扣除自身 20% 最大生命，造成 12 基础伤害（有瞄准 Buff 则翻倍为 24，释放后清空 Buff）。
- 意图栏区分「仔细瞄准」「骨箭（双倍）」等状态，让玩家能提前一回合决定防御。

## 四、新角色：空梦（KONGMENG）

角色选择界面新增 `[2] 空梦`，介绍「镜像与倒影的舞者」（测试角色，默认解锁）。

| 面板 | 值 |
|---|---|
| HP | 70 |
| 精力 | 12 |
| 力量 | 7 |
| 精准 | 4 |
| 防御 | 4 |

- **初始天赋**：欢愉之礼 —— 每次造成伤害时，在伤害管线中额外附加 1~3 点固定伤害（在乘区之前结算，可被一切乘法放大）。
- **初始四技能**：
  - 槽 1（锁）：镜像穿刺（近战，0 精力 CD0）—— 对最前方敌人造成 2 次 `力量×1.1 + 1`。
  - 槽 2（锁）：伪装（防御，1 精力 CD0）—— 护盾 = `防御×1.5`。
  - 槽 3：完美仿制（3 精力 CD2）—— 下次攻击伤害 ×0.7，但重复结算 3 次（每目标 3 段，均吃欢愉之礼等加成）。
  - 槽 4：镜光一瞬（AOE，4 精力 CD2）—— 对所有敌人造成 `力量×1.2 + 精准×1.1`。

## 五、角色专属池架构

0.2.5 起**天赋按角色完全专属、战斗技巧分通用/专属**：

- `Talent` 新增 `owner` 字段：归尘 6 个天赋 owner=GUICHEN，欢愉之礼 owner=KONGMENG。
- `CombatSkill` 的 `isExclusive` 改为 `owner`（null = 通用，非 null = 该角色专属）。
- `RunState` 的 `rollUnownedTalent` / `hasAnyUnownedTalent` / `rollUnownedCombatSkills` / `rollUnownedCombatSkill` 都按当前 `character` 过滤，别人的专属天赋/技巧抽不到。
- `Player` 新增 `Player(CharacterType)` 构造器，面板、初始技能、初始天赋全部来自 `CharacterData`，不再硬编码。

## 六、中途放弃本局（重开）

- `MapScreen`、`GameScreen` 底栏增加提示 `[ESC] 放弃本局`。
- 按 ESC 不再直接回主菜单，而是弹确认框：「确定要放弃本次游戏并重新开始吗？ [Y] 确定 / [N] 取消」。
- `Y`：丢弃当前 RunState，回主菜单重新开局；`N` / `ESC`：关闭确认框继续。
