# 归尘 · 0.2.7 — 角色选择视觉化与头像接入

本版本引入正式美术资源，把角色选择界面从纯文字重构为「背景 + 头像 + 鼠标交互」，并把战斗界面的玩家名字文本替换为像素头像。

## 一、资源与加载

美术资源位于 `assets` 目录（相对 `Gdx.files.internal` 的根）：

| 资源 | 路径 | 原尺寸 |
|---|---|---|
| 归尘头像 | `resources/image/role/guichen_role.png` | 8×8 |
| 空梦头像 | `resources/image/role/kongmeng_role.png` | 8×8 |
| 归尘背景 | `resources/image/role_ground/guichen_ground.png` | 1920×1080 |
| 空梦背景 | `resources/image/role_ground/kongmeng_ground.png` | 1920×1080 |

- 全部纹理由 `Main` 统一加载、统一 `dispose()`，各 Screen 只借用不释放。
- **防模糊**：所有头像纹理调用 `texture.setFilter(Nearest, Nearest)`，8×8 像素图放大时边缘才不糊。
- 加载遍历 `CharacterData.ALL`，不硬编码路径。

## 二、角色选择界面重构（CharacterSelectScreen）

1. **背景 Cover 裁切**：`drawBackgroundCover` 取「按宽贴边 / 按高贴边」中较大的缩放比例，等比放大直到铺满屏幕，居中绘制，超出部分由屏幕边缘自然裁切 —— 绝不拉伸变形。
2. 选中或悬停某角色时，该角色背景以 60% 透明度铺满（`batch.setColor(1,1,1,0.6f)` 后恢复 `Color.WHITE`）；未选中时纯黑。
3. **头像缩小**：渲染框 `BOX_SIZE = 96`（8 的 12 倍，整数倍缩放不撕裂），间距 36px —— 仿英雄联盟，以后角色多了也能并排放下。
4. **选中反馈 = 头像放大**（`SELECT_SCALE = 1.2`），**不再画金框**。
5. **右侧详情面板**：点击头像后，右侧弹出该角色的详情（名字 / 介绍 / 生命·精力·力量·精准·防御 / 初始天赋 / 初始技能），玩家可查看基础数据。
6. **实心确认按钮**：底部一个实心矩形「确认进入」按钮（未选中灰色、选中绿色、悬停亮一档），点击或按 Enter 进入；ESC 返回主菜单。

## 三、战斗界面头像替换（GameScreen）

- 左上玩家面板：原来显示角色名字的文本替换为 64×64（8 的 8 倍）头像，名字移到头像右侧，属性行改为紧凑格式（防/力/准）放名字下方。
- HP/MP 条、天赋、技巧渲染不变。

## 四、窗口图标替换

- libGDX 默认的窗口图标（「圆圈斜杠」logo，在任务栏/标题栏上看起来像禁止符号）换成游戏自己的图标：归尘 8×8 头像 Nearest 放大成 `icon16/32/64/128.png`，`Lwjgl3Launcher` 改为 `setWindowIcon("icon128.png", ...)`。

## 五、数据驱动

- `CharacterData` 新增 `avatarPath` / `backgroundPath` 字段。
- `Player` 新增 `character` 字段，界面层据此查纹理。
- 以后加新角色：补两张图 + 在 `CharacterData` 补一条数据，UI 类无需改动。

## 五、测试

- `BattleTest` 221 项断言保持全绿（逻辑层无变化）。
- UI 需手动验证：背景铺满不变形（重点拉大/缩小窗口）、头像点击后右侧弹出详情、选中放大无金框、实心按钮可点。

## 待办
