# 归尘 · 0.2.8 — 状态与诅咒、自定义角色与新敌人

本版本引入完整的负面状态与诅咒系统，新增「自定义角色（降临者）」捏脸系统，并扩充敌人、事件与宝箱机制。

## 一、负面状态与诅咒系统

### 状态（StatusEffect，战斗内临时、有回合数）
| 状态 | 效果 |
|---|---|
| 虚弱 | 造成的伤害 ×0.7 |
| 易伤 | 受到的伤害 ×1.5 |
| 晕眩 | 跳过本回合行动 |
| 中毒 | 每回合开始按「当前层数」扣血，随后层数 -1 |
| 流血 | 每次受伤额外扣「层数」血，随后层数 -1 |

### 诅咒（Curse，本局持续、不可消除）
| 诅咒 | 效果 |
|---|---|
| 恶魔抓痕 | 每次攻击自身受 2 点伤害 |
| 怠惰 | 每次攻击伤害 -10% |
| 旧疾 | 10% 概率跳过本回合 |

- 诅咒独立成 `Curse` 类，挂在 `RunState.curses`（与 `Player.curses` 共享同一列表），跨战斗保留。
- 结算钩子：回合开始（中毒扣血 → 晕眩/旧疾判定 → 回合递减）、受击后（流血）、伤害乘区（虚弱/易伤/怠惰/恶魔抓痕）。
- 中毒/流血靠「层数」自然消耗，不吃回合递减删除：中毒每回合开始扣「当前层数」血、层数 -1；流血每次受伤扣「层数」血、层数 -1。回合递减循环跳过这两者。
- 多段伤害（连续咬击、血刺、镜像穿刺等）每段独立触发流血/易伤。

## 二、自定义角色：降临者（捏脸系统）

- 角色选择界面增加 `[3] 降临者`，进入 `CustomCharacterScreen`。
- **10 点自由属性**分配到力量/精准/防御（初始均为 0），生命固定 50、精力固定 10。
- 键盘操作：`[A]/[D]` 加减、`[W]/[S]` 切换属性、`[R]` 重置、分配完 10 点才能 `[Enter]` 确认、`[ESC]` 返回。
- 默认头像为代码生成的 8×8 问号像素图（`Main.generateQuestionAvatar()`）。

### 降临者初始天赋「降临者」
第一次死亡时立即以 30% 最大生命原地复活（整局限 1 次，`descenderRevived` 标记）。

### 降临者四技能
| 槽 | 技能 | 类型 | 精力/CD | 效果 |
|---|---|---|---|---|
| 1 | 剑击 | 近战 | 0/0 | 力量×1.2 |
| 2 | 格挡 | 防御 | 1/0 | 护盾 = 3 + 防御×1.5 |
| 3 | 吃我一剑 | 远程 | 3/2 | 精准×5，自身下回合眩晕（斩杀技） |
| 4 | 厚积薄发 | 防御 | 1/2 | 下次攻击伤害 ×2.5 |

## 三、宝箱怪与宝箱节点

- 宝箱节点（TREASURE）有 **10%** 概率触发宝箱怪战斗（`RunState.rollTreasureMimic()`）。
- 宝箱怪（HP 45 / 防 2）七步循环：咬击(7) → 连续咬击(5×2) → 陈年宝箱 → 血盆大口 → 陈年宝箱 → 连续咬击 → 洗劫。
  - 陈年宝箱：下次受击附带 3 层中毒。
  - 血盆大口：20 伤害 + 必定 3 回合易伤。
  - 洗劫：偷走 10 金币。
- 胜利按精英战结算（天赋/技能二选一）+ 额外 20 金币。

## 四、专属天赋与技巧扩充

- **归尘专属技巧「锈蚀箭矢」**：所有远程伤害给敌人挂 2 层流血，多段每段独立触发。
- **空梦专属天赋「倒映」**：自身获得非晕眩负面效果时，给最前方敌人附加同样负面效果。
- **史莱姆王「腐液」→「腐蚀粘液」**：10 伤害 + 3 层中毒。
- **新敌人「凋亡骸骨战士」**（第 4~6 层普通池，HP 40/防 3）：挥砍(6) → 破伤风之刃(4，3 层流血) → 刺痛(5 层流血)。

## 五、新事件「遇见邪教徒」

- `[1] 粗略看看`：花 10 金币才能离开；金币不足则无法离开（只能选献祭）。
- `[2] 献祭`：随机 1 个诅咒 + 随机 1 个天赋。

## 六、金币迁移

金币从 `RunState.gold` 迁移到 `Player.gold`（金币是玩家拥有的资源，宝箱怪「洗劫」直接扣）。所有 `run.gold` 引用改为 `run.player.gold`。

## 七、测试

`BattleTest` 从 221 项增加到 **252 项全绿**，新增降临者面板/技能/复活、倒映反弹、锈蚀箭矢、宝箱怪、凋亡骸骨战士、邪教徒事件等断言。

## 八、选人界面与降临者点选（追加调整）

- **降临者可鼠标点选**：选人界面把可选列表统一成「正式角色 + 降临者」一起渲染，降临者头像纳入悬停/点击/选中/右侧详情面板，点确认进入捏脸界面（其余角色直接进地图）。
- **选人再仿英雄联盟**：头像缩小到 64×64，从左往右一排、每行最多 6 个，超过自动换行；多行整体居中。

## 九、属性纯鼠标 + 降临者自定义 + 事件选项（第二波追加）

- **属性加点只允许鼠标**：属性分配界面（ResultScreen）和降临者捏脸都去掉键盘加减，只保留鼠标点 `[-]` `[+]` 按钮。
- **降临者自定义名字/头像**：捏脸界面顶部名字栏（点击弹系统输入框，支持中文）与头像栏（点击弹文件选择器，选本地图片），确认后写入 `Player.name` 与角色头像。
- **邪教徒「离开」→「粗略看看」**：花 10 金币离开，金币不足无法离开。
- **祭坛「离开」→「摸索周边」**：+1 自由属性点。
- 事件效果接口改为返回 boolean（是否成功执行），支持「条件不满足则不推进」。
- 自检 252 → **257 项全绿**。

- **名字点击无效**：`Gdx.input.getTextInput` 在 lwjgl3 桌面端默认不可用，改用 Swing `JOptionPane` 弹输入框（支持中文）。

- 自检 257 → **259 项全绿**。

## 十、技能归属修复 + 切割技能 + 天佑天赋（第四波追加）

- **修复降临者检测到归尘技能**：`Skill` 增加 `owner` 字段（null = 通用），归尘三个可替换技能（蓄力 / 多重射击 / 血刺）标记为归尘专属；`rollUnownedReplSkill()` 按角色过滤，降临者/空梦不再从精英战奖励里抽到归尘技能。
- **降临者新技能「切割」**：耗 2 精力 CD2，使用后接下来 3 次攻击对目标附加 3 层流血（`player.slashCharges` 计数，每次攻击 -1）。
- **降临者新天赋「天佑」**：暴击率 +10%。
- 自检 259 → **268 项全绿**。

## 十一、流血结算 + 诅咒/状态显示 + 事件去重 + 帐篷主人（第五波追加）

- **补全敌人流血结算**：敌人身上的流血（锈蚀箭矢 / 切割挂上的）现在每次受击后额外扣「层数」血、层数 -1，与玩家流血同语义。
- **战斗界面显示诅咒与负面效果**：诅咒用完整名字（如「恶魔抓痕」）紫红色显示，负面效果用单字（虚 / 脆 / 晕 / 毒 / 血）+ 层数橙色显示，两者分块展示。
- **事件整局只遇一次**：`rollEvent()` 去重，已遇过的事件不再重复出现；全部遇过后降级成宝箱奖励。
- **废弃营地事件改造**：仔细搜刮 +20 金币（30% 惊动帐篷主人进入战斗）/ 粗略搜刮 +5 金币安全离开。
- **新增敌人「帐篷主人」**：50 血 / 10 防，四步循环（锤击 → 狂乱攻击 → 锤击 → 愤怒不已），胜利按普通战斗结算。
- 自检 268 → **280 项全绿**。
