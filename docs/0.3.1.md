# 归尘 · 0.3.1 — 召唤物 UI、毒叠加、多章节与圣骑士 Boss

> 本文件是 0.3.1 的**可运行快照**：只写「现在是什么」，计划放在最后。

## 一、召唤物 UI 与状态修复

- **召唤物显示**：战斗界面左面板（玩家面板下方、效果栏之后）新增「—— 召唤物 ——」区块，显示每个召唤物的名字 + 当前血量（如 `普通僵尸  HP 20/20`）。存活绿色，死亡置灰。
- **中毒叠加修复**：
  - `StatusEffect.addStacks` 本就是「层数相加」（旧层数 + 新层数，回合取较大值），叠加逻辑没问题。
  - 真正的 bug 是**敌人中毒从不结算扣血**：之前只把毒叠在状态栏里好看。现已补全 `BattleSystem.tickEnemyStatusAtTurnStart()`——敌方回合开始，每个敌人按当前层数扣血，随后层数 -1（毒一层层挥发）。
  - 所有「自身 / 召唤物给敌人上毒」统一走 `BattleSystem.applyPoisonToEnemy(target, stacks)`，不再各自直接 `addStacks`。

## 二、多章节底层架构（Chapter 系统）

- **`Chapter` 枚举**：`SWAMP`（沼之森）/ `SOUTHERN_LAND`（南边领地）。
- **`RunState.currentChapter`**：一局状态新增章节字段。
- **`EnemyPool` 按章节抽取**：`create(type, floor, rng, chapter)` 四参接口，旧三参保留（默认沼之森）。
- **防混合规则**：南边领地只出骑士系（见习/冲锋/皇家守卫/骑士长），不出史莱姆和骸骨。
- **章节选择入口**（`ChapterSelectScreen`）：选完角色后、进地图前弹章节选择，纯鼠标点选或 [1]/[2] 快捷键，[ESC] 返回角色选择。降临者捏脸后同样经过此界面（带 `prebuiltPlayer`）。
- 地图顶栏章节名、通关结算文案（「腐化史莱姆王倒下了」/「年轻的骑士长倒下了」）均按 `currentChapter` 区分。

## 三、新章节敌人（南边领地）

- **见习骑士**（普通，50 血，防 2）：挥剑(6) → 盾击(4，自身获得 3 护盾) → 循环。
- **冲锋骑士**（普通，65 血，防 1）：长矛突刺(8) → 蓄势冲锋(下回合 15 伤害) → 循环。
- **皇家守卫**（精英，90 血，防 4）：横扫(7) → 坚守阵地(获得 15 护盾，回 5 血) → 破甲击(10，给玩家 2 层易伤) → 循环。

> 敌人护盾真正生效：`Enemy` 新增 `shield` 字段 + `absorbByShield(damage)`，玩家/召唤物伤害先扣护盾、不够再扣血（`calculateDamage` / `minionAttack` 都接入）。

## 四、第二章 Boss：年轻的骑士长（120 血，防 5）

- **AI 用 `int[] SEQUENCE` 数组管理循环序列**，不写 if-else 大乱炖。
- **骑士礼仪**（开局第 1 回合必定）：双方各扣 10 点**真实伤害**，独立方法 `knightlyCourtesy()`，直接 `takeDamage` 扣血，无视护盾 / 免伤 / 易伤。
- **常规循环**（7 步）：
  1. 骑士突刺：10 伤害
  2. 神圣一击：20 伤害（重击）
  3. 祈祷：回 10 血 + 2 回合 10% 免伤（`damageTakenMult = 0.9`）
  4. 瞬息连刺：8 伤害 x3（多段）
  5. 圣洁之心：清除自身所有负面效果
  6. 骑士突刺：10 伤害（穿插）
  7. 圣水洗礼：后续所有伤害永久 +20%（可叠加，最高 3 层）
- 免伤通过 `Enemy.damageTakenMult` 实现，`getIntent()` 会按当前附魔层数实时显示伤害。

## 五、商店与道具扩充

- **商店 6 槽**：属性点（15/30/50 递增）、清除诅咒（50 起 +15）、随机药水（10~15）、随机战斗技巧（40）、生命上限 +5（35）、随机药水（第二槽）。
- **存档骨架**：`Main.SaveManager` 静态类预留（`SAVE_FILE` / `enabled()` / `save()` / `load()`），第一版不做本地 IO，只搭结构。

## 六、新通用技巧

- **老毒物**：自身和召唤物对敌人造成的中毒效果额外 +1 层（如僵尸撕咬 3 层毒 → 4 层）。
